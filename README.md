# wm-policy-portfolio (WMPP)

**World-Model Policy Portfolios**: test-time arbitration over a bank of frozen
goal-conditioned policies on [OGBench](https://github.com/seohongpark/ogbench).

Given several frozen goal-conditioned policies trained by different offline GCRL
algorithms (GCBC, GCIVL, GCIQL, QRL, CRL, HIQL) on the *same* dataset, a learned
state-space world model plus a shared metric value function picks, every `c` env
steps, which policy should act now. Nothing is retrained. Over 19 OGBench datasets
this beats the best single policy in the bank (mean success 42.2 vs 31.9) and a
random-switching control with the same commitment schedule (27.3).

## Method in one paragraph

`planners/portfolio.py:RolloutRanker`. Every `c` real steps, roll each bank policy
forward `k` imagined steps through an ensemble of `E=3` one-step MLP dynamics
models (closed loop: each policy acts on its own imagined states), score every
imagined state with the ensemble-mean metric value
`V(s,g) = -||φ_S(s) − φ_G(ψ(g))||`, take the max over the horizon, execute the
arg-max policy for `c` steps, repeat. Only the diagonal `k = c` is used, so the
model budget per env step is `P·E` regardless of the cell. The single ablation,
`RandomArbiter`, draws a policy uniformly every `c` steps with no model calls.

## Layout

```
interfaces/    FrozenPolicy (restores OGBench impls checkpoints, deterministic act), PolicyBank, SimBranch
world_model/   EnsembleWorldModel + LAVL metric value head, sequence dataset, imagined rollouts
planners/      RolloutRanker (WMPP), RandomArbiter, and the one-step chooser
evaluation/    paired-episode harness, static/dynamic oracle, diagnostics, hierarchical bootstrap
scripts/       train_policy.py, train_world_model.py, eval_planner.py, report_og50.py,
               make_paper_assets.py, onboard_env.py, SLURM templates, policy-bank manifests (*.csv)
manifests/     wmpp_env_config.json — per-env registry (policy root, WM checkpoint, baselines)
tests/         pytest gates (determinism, planners, world model)
WMPP_ICLR2027/ paper source; tables/ and figures/ are generated by scripts/make_paper_assets.py
```

## Setup

```bash
python3.10 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# Pinned OGBench (never modified by this repo):
git clone https://github.com/seohongpark/ogbench && (cd ogbench && git checkout 1d41409 && pip install -e ".[train]")
export OGBENCH_IMPLS=/path/to/ogbench/impls MUJOCO_GL=disable JAX_PLATFORMS=cpu   # GPU: drop JAX_PLATFORMS
```

Policy training uses the unmodified OGBench reference implementations
(`ogbench/impls/main.py`); this repo only restores their checkpoints.

Large artifacts (policy checkpoints, world-model checkpoints, per-episode eval
outputs, datasets, SLURM logs) are not in this repository. Default paths in the
scripts point at our cluster layout — override them
with the corresponding flags (`--policy_root`, `--wm_dir`, `--out_dir`,
`--eval_root`, `--report`) or the `OGBENCH_IMPLS` environment variable.

## Pipeline

1. **Policy bank** (GPU): `scripts/slurm_train_array.sbatch` over a
   `scripts/*_manifest.csv` (one row per env × algorithm × seed; OGBench defaults).
2. **World model + metric value head** (GPU): `scripts/slurm_train_wm.sbatch` →
   `scripts/train_world_model.py` (per-family hyperparameters in `RUNBOOK.md` §3.2).
3. **Planner evaluation, og50 protocol** (CPU): `scripts/eval_planner.py` — official
   OGBench 5 tasks × 50 episodes per bank seed, identical per-episode reset seeds for
   every method, `k=c ∈ {1,5,10,25,50,100}` plus Random at every `c`; fixed-policy
   baselines are re-evaluated on the same episodes (`--out_tag=og50fx`) so every Δ
   is a paired contrast.
4. **Report**: `scripts/report_og50.py --fixed_tag=og50fx` → markdown + JSON.
5. **Paper assets**: `scripts/make_paper_assets.py` writes `WMPP_ICLR2027/{tables,figures}/`
   (including `tables/numbers.tex`, the macros used in the running text — never
   hand-edit numbers in `main.tex`), then `cd WMPP_ICLR2027 && latexmk -pdf main.tex`.

## Tests

```bash
JAX_PLATFORMS=cpu MUJOCO_GL=disable OGBENCH_IMPLS=/path/to/ogbench/impls \
  python -m pytest -q tests/test_planners.py tests/test_world_model.py
```

`tests/test_snapshot_determinism.py` and `tests/test_frozen_policy_restore.py`
need trained checkpoints and take minutes.

## Statistics

Δ vs best policy and method-vs-method contrasts use a hierarchical bootstrap
(resample bank seeds, then episodes within seed; 10k resamples; 95% percentile
CI), paired per episode. No multiple-comparison correction is applied.
